# PROY 1
# TP GitHub y Jira - Análisis de Ventas

## Escenario elegido
Escenario B - Análisis de ventas de una pequeña empresa

## Descripción
Este proyecto analiza datos de ventas utilizando Python, GitHub, Jira y Google Colab.

## Estructura del proyecto

- /datos → datasets CSV
- /scripts → scripts Python
- /resultados → gráficos y resultados

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Jira
- Google Colab

## Ejecución

Ejecutar:

scripts/analisis_datos.py

El script genera estadísticas básicas y gráficos de ventas.
